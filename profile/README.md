## SyntaxShift 

The repositories include [**k3s-setup**](https://github.com/p7-projekt/k3s-setup) for configuring a k3s Kubernetes cluster, [**api-backend**](https://github.com/p7-projekt/api-backend) for a C# backend API, and [**frontend**](https://github.com/p7-projekt/frontend), built using **SvelteKit** and TypeScript. The [**.github**](https://github.com/p7-projekt/.github) repository contains GitHub-specific configuration files, such as workflows or templates. [**mozart**](https://github.com/p7-projekt/mozart) is a Rust-based test composer and runner, while [**performance-test**](https://github.com/p7-projekt/performance-test) focuses on performance testing using **k6** and JavaScript. All repositories are under the MIT License and were recently updated.
