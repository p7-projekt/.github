## SyntaxShift 👋

The repositories include k3s-setup for configuring a k3s Kubernetes cluster, api-backend for a C# backend API, and frontend, built using SvelteKit and TypeScript. The .github repository contains GitHub-specific configuration files, such as workflows and templates. mozart is a Rust-based test composer and runner, while performance-test focuses on performance testing using k6. All repositories are under the MIT License and were recently updated.
